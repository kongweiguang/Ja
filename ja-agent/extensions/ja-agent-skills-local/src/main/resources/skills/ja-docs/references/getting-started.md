# 开始使用 Ja

## 第一次对话

1. 安装桌面版后，打开 **设置 -> 模型 -> 新增供应商**，选择实际 API 规范，填写服务地址和 API Key，并加入真实的上游模型标识。保存后选择模型；“验证模型”会发起一次真实请求，可能产生服务商费用。
2. 选择“无项目对话”，或在左侧添加本地项目。无项目主会话拥有自己的本地工作目录；项目会话使用所选目录。Ja 先取得项目的信任决定，可信项目的配置和指令才会参与执行。
3. 在输入框直接描述要处理的事情，也可附加文件或图片、引用工作区文件或 Skill。发送前检查当前模型和执行确认模式。“需要确认”会为适用的工具操作请求批准；“全部执行”使用当前用户的实际系统权限，不等于操作系统沙箱。
4. 实施类任务直接在普通对话中执行；Ja 会根据实际结果继续实施、验证并修正，最后交付结果。运行中可补充要求、回答澄清或停止本轮。终答会说明完成项、验证结果和未解决事项；未核实的结果不要当成完成。

## 会话与工作台

- 左栏按项目或“无项目对话”查找主会话。每个会话保留自己的对话、模型和执行确认偏好；切换会话后右侧 Files、Review、Terminal、Browser 也切到该会话的目标。
- 点击回复中的本地文件路径可在右栏预览；Review 用于对照文件差异，Files 用于浏览工作区，Terminal 用于运行命令，Browser 用于查看本地页面。隐藏右栏能力时不必让未选中的工作面继续扫描。
- 文件引用和附件是当前消息的上下文，不会自动把整个目录发送给模型。模型服务会收到这次请求中实际附带的对话和附件；MCP/浏览器可能按配置访问其它服务。
- `/plan` 是可选的单次任务规划流程，适合先形成和确认方案，再通过明确的“执行”动作启动。普通实施任务无需先使用 `/plan`；计划草稿或回答澄清本身不授权执行，暂停或停止计划不会自动回滚已经改动的文件。

## 操作 Ja 本身

让 Agent 代改 Ja 时，先说明目标作用域，例如“把全局默认模型改为 X”或“只在这个项目禁用某个 Skill”。模型、权限和扩展优先走设置页；需要核对字段时读配置参考。删除 Provider/模型、清除凭据、停止后台或处理结果未知的工具前，先看当前状态及其对会话的影响。
