# Ja 命令行

本页仅适用于已经单独安装 `ja` CLI 的用户。CLI 仍在开发中，不应假定桌面安装包自带 `ja` 命令。先运行 `ja --version` 与 `ja --help` 确认当前 PATH 指向的版本和可用参数。

| 命令                         | 用途                                                             |
| ---------------------------- | ---------------------------------------------------------------- |
| `ja`                         | 在当前目录开始交互会话。                                         |
| `ja -C <目录> [任务]`        | 在指定目录开始会话，可同时给出首条任务。                         |
| `ja resume [thread-id]`      | 恢复当前工作区中的会话，或按 ID 恢复指定会话。                   |
| `ja exec [-C <目录>] <任务>` | 非交互运行，普通 stdout 只输出最终回答。`-` 从标准输入读取任务。 |
| `ja exec --json <任务>`      | 输出带会话身份和终态的 JSONL 事件，供自动化处理。                |
| `ja setup`                   | 随时管理全局供应商、模型、API Key 与默认模型。                   |
| `ja server status`           | 查看本机后台状态。                                               |
| `ja server stop [--force]`   | 停止本机后台；先检查仍在进行或等待处理的任务。                   |

交互界面输入 `/` 查找命令，`@` 选工作区文件，`$` 选已发现 Skill；`Ctrl+J` 换行，空输入时 `Ctrl+D` 退出。CLI 与桌面共用 Ja App Server、模型配置和持久会话，关闭终端只是断开客户端，不代表后台任务已取消。

`/model` 保留会话模型切换，也提供“管理模型”。未配置模型时仍能浏览历史并打开设置；不需要桌面端或手改文件。
模型设置使用 `Tab/Shift+Tab` 切换字段，`F2` 展开高级项，`Ctrl+S` 保存，`Esc` 返回，`F5` 刷新或核实。
更改全局默认不改变既有会话，项目覆盖继续生效。保存不自动调用模型；“验证连接”需先确认一次真实请求及可能的费用。
密钥待补齐时保留已保存供应商并复用原 ID 重试；回执待核实时按 `F5` 核实，不自动重复提交。

`ja exec` 成功返回 0；执行失败为 1，参数错误为 2，等待用户审批或澄清为 3，连接或协议失败为 4，主动取消为 130。返回 3 时使用会话 ID 在交互界面或桌面处理等待项，不能把已受理当成已完成。`--json` 自动化应以真实终态事件判断结果，不以进程启动或中间文本判断。
