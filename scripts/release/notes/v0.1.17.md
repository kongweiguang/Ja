## 不兼容变更

- Skills 配置升级为 `schema_version = 2`：用户配置仅保存 `user:`/`ja:` 标识，可信项目配置仅保存
  `project:` 标识和可选 `disabled_skills`。旧 `[[skills]]` 配置不会自动兼容；升级前会备份，旧项目授权需在
  对应项目中重新显式开启。

## 改进

- 配置、Skills 与 MCP 的运行时文档支持原子读取、诊断与最近可用快照恢复，项目级 Skills 可独立启用或停用。
- 对话工作过程按真实时间顺序保留流式正文、工具、失败与恢复信息；完成的工作过程收起为可访问的历史摘要。
- Composer 显示最近请求的上下文用量；失败且没有草稿时可直接以新 Turn 继续回复。
- Tool 的不确定执行支持明确的重试或跳过决策，并将恢复事实持久化后投影到历史记录。

## 修复

- 修复启动恢复、历史读取与运行时重载之间的状态漂移，确保线程用量、任务状态和配置代际按同一权威快照呈现。
- 修复 Windows 主机进程与 JA-RPC 传输在停止、重启和配置变更期间的资源清理及错误投影。
