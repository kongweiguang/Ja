## 改进

- Ja 0.2.0 建立新的 Java 25 Agent Kernel 基线，拆分 Core、存储扩展、Skill 扩展与 App Server；统一 JA-RPC v2，保留独立 Plan，并提供 Spring Boot 接入示例。
- CLI 增加共享模型管理、非交互执行、会话恢复、运行中输入队列、终答导出与 Review；桌面端完善会话分叉、命令会话、项目管理、存储恢复和工作台审查，并与 CLI 共用 ja-review。

## 数据兼容

- 0.2.0 使用新的 SQLite V1 数据基线，不会迁移旧数据库或导入旧会话；不符合 0.2 schema 的数据库会阻断业务启动。若要保留旧版数据，可先备份旧数据，再将 `JA_HOME` 指向新的绝对目录后启动 0.2；新目录不会导入旧配置或工作区登记，需重新配置模型并添加工作区。原 `.ja` 和项目文件夹会保持原样，不会被此操作删除。

## 分发与供应链

- Windows 与 macOS 安装包不启用系统签名或公证；Tauri updater 文件继续使用更新签名。
- 同版本同步发布 Windows x64 npm CLI，要求 Node.js 24.x：`npm install -g @kongweiguang/ja@0.2.0`。
- 供应链报告会披露第三方许可证批准归档尚未建立及相关审阅未完成，不会将其标记为 `approved` 或 `complete`。
