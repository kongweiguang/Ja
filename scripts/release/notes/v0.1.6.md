## 改进

- 切换已访问项目时优先恢复缓存的会话与历史，后台核对更新，减少清空后重新加载的等待感。
- 按会话保存阅读位置，切回时恢复；正在跟随最新消息的会话继续跟随回复。
- 将加载提示统一为“最近对话”右侧的小加载圈，读取期间保留现有列表。

## 修复

- 修复项目切换时“正在读取”占位突然出现、消失造成的列表跳动。
- 保留跨项目切换期间的后台会话投影，并在运行时重启或缓存失效时重新读取。

安装包未使用 Windows Authenticode 或 macOS Developer ID/公证；Tauri 更新包继续保留签名与校验。依赖许可证批准归档仍未完成，供应链报告保留实际审查状态。
