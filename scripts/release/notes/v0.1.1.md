## 新功能

- 侧边任务支持独立会话、创建时上下文继承、显式消息投递和关闭清理。
- Plan 与 Goal 支持结构化交互、只读工具策略、完成评估审计和恢复。
- 支持模型推理内容展示与 Provider 推理能力声明。
- 新增界面偏好和窗口关闭行为设置。
- 支持 MCP 工具按需发现，减少一次性加载的工具信息。

## 改进

- 完善 JA-RPC 合同、持久化迁移和桌面端 API 适配。
- 优化对话、任务及 Plan/Goal 的持久化、恢复、取消和清理流程。
- 更新 README 与界面截图，补充当前功能和安装说明。

## 修复

- 修复侧边任务、历史记录和 Goal/Plan 在恢复与继续执行时的状态边界问题。
- 修复模型响应、推理内容、交互请求和 RPC 事件在异常流程中的映射与恢复问题。
- 修复发布校验中 Native Image 体积预算与实际产物不一致的问题。
