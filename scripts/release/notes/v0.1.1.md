Ja 0.1.1 继续完善桌面工作台与 Agent Harness 的交互闭环，重点覆盖侧边任务、Plan/Goal 交互、推理内容、设置偏好和 MCP 工具发现。

- 支持侧边任务的独立会话、创建时上下文继承、显式消息投递和关闭清理。
- 支持结构化交互问题、Plan 只读工具策略、Plan 完成评估审计与 Goal 恢复边界。
- 支持模型推理内容、Provider 推理能力声明、界面偏好和窗口关闭行为设置。
- 扩展 JA-RPC 合同、持久化迁移、桌面端 API 适配和相关回归测试。

安装包包括 Windows x64 NSIS、macOS Intel 与 Apple Silicon DMG；`*.app.tar.gz` 是 macOS 自动更新产物。

安装包未使用 Windows Authenticode 或 macOS Developer ID／公证证书，首次打开可能出现系统安全提示。Tauri 更新签名保持启用，发布提供 `latest.json`、独立签名文件、产物清单与 SHA-256 校验和。

当前供应链报告包含真实依赖/BOM 数据；第三方许可证批准归档尚未完成，不宣称已完成法律审查。Ja 源码以 GPL-3.0-or-later 发布。

升级前请备份重要项目，以及 `%USERPROFILE%\\.ja` 或 `~/.ja` 中的数据。
