## 改进

- 文件搜索改为复用原生 `fd`/`rg` 搜索语义，保留 Git ignore、glob、hidden 和 no-follow 边界，避免大型工作区被 Java 全树遍历拖住。
- 为 JVM、Native Image 和 Tauri sidecar 统一提供版本固定、带校验和与许可证的搜索工具资源，并在 CI 中执行同一套搜索验收。

## 修复

- 修复 `find README*` 等工作区工具在包含大量 `.venv` 或其它 ignored 文件的项目中长时间停留在“正在工作”的问题。
- 修复搜索进程取消、截止时间、输出上限、非 UTF-8 输出、Windows junction 和工作区越界等边界处理，保留可纠正的工具错误结果。
