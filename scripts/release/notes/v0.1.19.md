## 改进

- 每个会话独立保留自己的右侧工作台状态，切换会话后可继续使用各自的文件、终端和预览页面。
- 回复中的本地文件链接可直接打开预览；支持代码、HTML、图片和 PDF，并可从 Windows 定位到资源管理器中的文件。
- 网页预览支持多标签、地址栏、前进、后退和刷新。
- Composer 增加上下文菜单和剪贴板图片粘贴操作。

## 修复

- 修复预览标签切换、关闭和恢复期间的原生页面状态同步与资源清理问题。

## 分发与供应链

- Windows 与 macOS 安装包未启用系统代码签名或公证；Windows 安装器与两种 macOS 更新包均通过 Tauri updater 签名验证。
- 本版本已生成 Node、Rust、Maven 与安装包的供应链证据，但报告状态为 `blocked`：仓库缺少经审阅的第三方许可证文本归档（`LICENSE_ARCHIVE_EMPTY`）；Windows x64 证据另记录 `GIT_TREE_DIRTY`。这些状态保持未批准，未标记为 `approved` 或 `complete`。
