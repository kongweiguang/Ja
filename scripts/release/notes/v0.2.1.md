## 改进

- 完善 CLI 全屏排版、消息详情、剪贴板、粘贴和 Windows 外部编辑器交接，并为历史读取增加边界校验。
- 自动上下文压缩支持实时状态同步和重连恢复；CLI 展示压缩与模型请求的工作状态，摘要请求沿用当前 Turn 的模型参数。
- 本地文件引用使用明确的绝对路径，保留 Windows 路径的行列定位并显示完整目标提示；移除按同名文件猜测目标的选择流程。
- 修复浏览器预览中迟到的加载快照覆盖已完成导航的问题，保持标题、地址和前进后退状态一致。

## 分发与供应链

- Windows 与 macOS 安装包不启用系统签名或公证；Tauri updater 文件继续使用更新签名。
- 同版本同步发布 Windows x64 npm CLI，要求 Node.js 24.x：`npm install -g @kongweiguang/ja@0.2.1`。
- 修复 npm 安装时启动脚本换行规范化导致的完整性校验误报，更新桌面与 CLI 入门说明。
- 供应链报告继续如实披露第三方许可证批准归档及审阅状态，不将未完成事项标记为已批准。
