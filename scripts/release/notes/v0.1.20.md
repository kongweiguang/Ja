## 改进

- 长回复支持按需读取完整正文并导出文本。
- 能力设置新增项目选择入口，可按项目查看和调整适用范围。
- 改善断线后的 Turn 与审批恢复、重复提交保护和任务恢复。
- 改善 Provider 流式响应与计划评估重试。
- App Server 启动时自动应用数据库迁移并保留已有会话数据。

## 修复

- 修复工作区路径搜索候选处理、首次创建会话冷启动和运行时关闭时序问题。

## 分发与供应链

- Windows 与 macOS 安装包未启用系统签名或公证；updater 文件带有 Tauri 签名。
- 供应链报告仍为 `blocked`（`LICENSE_ARCHIVE_EMPTY`；Windows x64 另有 `GIT_TREE_DIRTY`）。
