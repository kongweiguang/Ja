## 新功能

- 新增 Ja CLI 终端客户端，支持交互会话、恢复已有会话、非交互执行与 JSONL 事件输出。桌面端和 CLI 共用本机 App Server、模型配置及会话记录。
- 新增本地 App Server 常驻服务和共享运行时，使关闭终端界面后，已接纳的任务仍由服务端继续管理。

## 改进

- 增加客户端操作回执、用户输入历史和完整回复分页读取，改善断线后的状态核实与长回复读取。
- 改善 Provider 流式响应、计划评估重试和任务恢复过程，避免对执行状态未知的操作自动重复提交。
- 增加完整回复导出及能力项目选择入口。

## 兼容性与分发

- 数据库迁移会由 App Server 启动时自动应用。
- Windows x64 的 `@kongweiguang/ja` npm 包已加入构建与发布流程，但目前尚未公开；本次公开桌面安装包不包含可安装的 npm CLI 包。
- Windows 与 macOS 安装包未启用系统代码签名或公证；Tauri updater 仍通过独立签名验证。
