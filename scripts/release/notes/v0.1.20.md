## 桌面端改进

- 长回复支持按需读取完整正文并导出文本。
- 能力设置新增项目选择入口，可按项目查看和调整适用范围。
- 改善桌面断线后的 Turn 与审批恢复、完整回复读取和重复提交保护。
- 改善 Provider 流式响应、计划评估重试及任务恢复。

## 兼容性与分发

- App Server 启动时自动应用数据库迁移，保留已有会话数据。
- 本次 `v0.1.20` 是桌面端正式版。Ja CLI 仍在开发中，不属于本次正式版交付；`@kongweiguang/ja` npm 包未发布。
- Windows 与 macOS 安装包未启用系统代码签名或公证；Tauri updater 仍通过独立签名验证。

## 供应链证据

- 本版本已生成 Node、Rust、Maven 与安装包的供应链证据，但审计报告状态为 `blocked`：仓库缺少经审阅的第三方许可证文本归档（`LICENSE_ARCHIVE_EMPTY`）；Windows x64 证据另记录 `GIT_TREE_DIRTY`。这些状态未获批准，未标记为 `approved` 或 `complete`。
