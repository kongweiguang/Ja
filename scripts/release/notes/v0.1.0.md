## 新功能

- 首次提供基于 Java 25 App Server 和 Tauri 桌面工作台的 Ja 预览版本。
- 支持 Anthropic Messages、OpenAI Chat Completions 和 OpenAI Responses 协议。
- 支持流式对话、Tool 执行与审批、Skills、MCP、附件和上下文管理。
- Plan 与 Goal 独立管理，右侧工作台按会话保留状态。

## 改进

- 建立从桌面工作台到 Agent Runtime 的分层运行链路。
- 接通对话、文件、Review、终端和浏览器等核心工作面。
- 提供持久化会话历史、模型设置、项目目录和工作区操作能力。

## 修复

- 修复桌面运行时退出、终端输出、MCP 客户端清理和模型协议识别等边界问题。
- 修复跨 Java、Rust 与 TypeScript 层的协议映射和生命周期问题。
