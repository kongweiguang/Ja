Ja 0.1.0 是首个桌面预览版本。Java 25 App Server 负责 Agent 运行、配置与持久化，Tauri 桌面工作台提供对话、文件、Review、终端和浏览器能力。

- 支持 Anthropic Messages、OpenAI Chat Completions 和 OpenAI Responses 协议。
- 支持流式对话、Tool 执行与审批、Skills、MCP、附件和上下文管理。
- Plan 与 Goal 独立管理，右侧工作台按会话保留状态。

安装包包括 Windows x64 NSIS、macOS Intel 与 Apple Silicon DMG。请按设备架构选择文件；`*.app.tar.gz` 是 macOS 自动更新产物。

安装包未使用 Windows Authenticode 或 macOS Developer ID／公证证书，首次打开可能出现系统安全提示。Tauri 更新签名仍保持启用，发布提供 `latest.json`、独立签名文件、产物清单与 SHA-256 校验和。

当前供应链报告包含真实依赖/BOM 数据；第三方许可证批准归档尚未完成，不宣称已完成法律审查。Ja 源码以 GPL-3.0-or-later 发布，源代码可通过本版本 tag 获取。

预览版本使用前请备份重要项目，以及 `%USERPROFILE%\.ja` 或 `~/.ja` 中的数据。
