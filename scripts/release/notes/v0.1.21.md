## 改进

- 桌面对话时间线加载更早记录时改用原位旋转指示，避免加载文字挤动内容布局。
- 精简导航侧栏底部区域；运行时恢复提示集中在设置视图中处理。
- Ja CLI 输入区按内容调整终端占用高度，窗口缩放后同步适配；恢复会话空态和操作提示更明确。

## 修复

- 修复桌面端首次读取运行时仍处于启动状态、随后收到就绪事件时，未重新核验运行时身份并恢复 Turn 准入的问题。

- Windows 与 macOS 安装包不启用系统签名或公证；updater 文件使用 Tauri 签名。
- CLI 的 npm 包使用独立发布流程，不包含在本次桌面安装包中。
- 供应链报告会如实披露尚未归档的第三方许可证审阅材料，不标记为已批准。
